# Прототип ИИ-проверки домашних заданий

Концепт для LMS Alles: ученик, куратор и методист, светлая и тёмная темы, десктоп и телефон.

## Что здесь

- `index.html` — весь прототип одним файлом (около 310 КБ). Внутри React, шрифт Manrope и страница токенов. Работает без интернета и без сервера: файл можно открыть двойным щелчком, отправить или выложить на любой хостинг статических сайтов.
- `png/` — 14 кадров в светлой теме: 7 состояний на десктопе (1440 px) и на телефоне (390 px).
- `source/` — исходники. Экраны в `Main.dc.html`, токены в `Tokens.dc.html`, `runtime.js` исполняет их в браузере.

## Как пользоваться прототипом

Панель сверху переключает роль (ученик, куратор, методист), состояние экрана ученика, тему и устройство. Кнопка «Токены» открывает страницу дизайн-токенов. Если открыть прототип на телефоне, он сразу покажет телефонную раскладку на весь экран.

Отдельный экран без панели открывается параметрами адреса:

```
index.html?screen=curator&device=phone&theme=dark&chrome=off&h=1560
```

`screen`: result, checking, appeal, appeal-sent, rework, curator, methodist. `device`: desktop, phone. `theme`: light, dark. `h` — высота кадра в пикселях.

## Как пересобрать после правок

```
node source/build.mjs
```
